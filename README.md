# Automatizacion QA - Saucedemo

Proyecto de automatizacion de pruebas realizado con python para el curso de Talento Tech. 

## Tecnologias usadas
- Python 
- Selenium
- Pytest
- Git
- Github

## Instalacion

Instalar las dependencias:

    ``` python
    pip intall selenium
    ```
    ``` python
    pip intall pytest
    ```
    ``` python
    pip intall pytest-html
    ```

## Ejecutar las pruebas

    ``` python
    pytest
    ```

## Casos de prueba
- Login exitoso
- Agregar producto a carrito
- Verificar producto a carrito
